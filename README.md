
# Aula 06 - Git e GitHub

## Descrição

Repositório criado para a realização da atividade da Aula 06,
com o objetivo de praticar Git, GitHub, commits, repositórios
remotos e comandos de publicação.

## Como executar

Clone o repositório utilizando:

git clone git@github.com:SEU-USUARIO/aula-06-git.git

Entre na pasta:

cd aula-06-git

Depois, execute os arquivos do projeto conforme as instruções
da atividade.
